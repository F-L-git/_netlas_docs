# How to Get an API Key

An API key is intended for user authorization via Netlas API. It acts as a secret authentication token for the API user. Each registered Netlas user has his own unique API key, which he can use to access the API. The key is located on the [profile page](https://app.netlas.io/profile/), which is accessible from the menu in the upper right corner of the web application.

!!! warning "Keep your API key secret!"

    It is important to keep your API key secure to prevent unauthorized access to the API and to ensure that the service cannot be used in a way that you have not authorized. If you suspect that your API key has been compromised, you can reissue it by clicking on the  "Change API key" button.
