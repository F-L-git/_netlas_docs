# Netlas Documentation Portal

This portal is dedicated to using the [Netlas.io](https://netlas.io) platform. Here, you will find all the necessary information regarding the application, its features, and automation development using the Netlas API and SDK.

Netlas.io is a suite of tools designed for cybersecurity research and IT auditing. The platform indexes billions of facts about live internet hosts, including exposed ports, running services, and more. It gathers additional information, such as DNS records, WHOIS data, and threat intelligence data, making Netlas invaluable for understanding the global digital landscape. The platform also includes powerfull attack surface management tools and datastore.
